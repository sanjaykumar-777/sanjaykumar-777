## 👨‍💻 About Me

I'm an SDET with **3+ years** building automation systems for **enterprise FinTech SaaS**. I don't just write test scripts — I architect frameworks: modular, scalable, and built to survive a product that changes every sprint.

Lately, that scope has expanded into testing **AI itself** — validating LLM outputs for financial data extraction with the same rigor I'd apply to any critical system. I use tools like **Claude Code** and **GitHub Copilot** daily to move faster without cutting corners on quality.

- 🏗️ Architected a **Playwright framework** (POM + API abstraction + MySQL validation) → 250+ scenarios, 150+ APIs, ~90–100% coverage
- ⚙️ Wired automation into **GitHub Actions** as release quality gates → prevented 20+ production defects
- 🤖 Designed & tuned **LLM prompts** for remittance extraction/prediction models; built validation pipelines for model output accuracy
- 🚦 Owned **weekly production releases** — deployment plans, rollbacks, post-release verification
- 🐛 Debugged **Spring Boot** services live across environments using Datadog, SQL & Postman
- 🧑‍🏫 Mentored junior SDETs and drove **Shift-Left testing** across a 10-member Agile team
